# 轮子：启动、验收与备份（多租户框架）

## 1. 目录说明
- frontend：前端（Ant Design 风格后台）
- backend：后端（Node + Express + SQLite）
- docs：产品/架构文档与本说明

## 2. 首次启动（本地）

### 环境要求
- Node.js 22+（后端使用 Node 内置 sqlite）

### 2.1 启动后端
在 backend 目录：
- npm install
- npm run dev

默认：
- 后端地址：http://localhost:3000
- 平台管理员账号：admin
- 平台管理员密码：admin123（可用 backend/.env 修改 SEED_ADMIN_PASSWORD）

### 2.2 启动前端
在 frontend 目录：
- npm install
- npm run dev

前端地址：
- http://localhost:5173/login

## 3. V1 验收清单（你可以拿这个当“轮子完成标准”）

### 3.1 登录
- 用 admin/admin123 登录后进入平台端租户管理页
- 使用租户管理员账号密码登录后进入租户端首页

### 3.2 创建租户
- 平台端可新建租户（包含租户名称、租户管理员账号/显示名/初始密码）
- 创建成功后前端会提示“初始密码”（仅用于你记录/交付给客户）

### 3.3 启用/停用租户
- 平台端可停用租户
- 租户停用后，该租户管理员不能登录（提示租户已停用）

### 3.4 重置租户管理员密码
- 平台端在租户详情里可重置密码
- 重置成功后前端会提示“新密码”
- 用新密码可登录租户端

### 3.5 多租户地基
- 租户管理员登录后可在租户端首页看到 tenant_id
- 后端会在 token 中携带 tenant_id，用于后续业务数据隔离

## 4. 重要约定（保证后续接业务不返工）
- tenant_id 必须来自后端登录态，不从前端随便传入信任
- 密码不支持回看，只支持重置；创建/重置时可一次性把新密码展示出来用于交付

## 5. 备份为“轮子模板”（复制即用）

### 5.1 最简单备份方式（推荐）
把下面目录整体打包保存：
- backend
- frontend
- docs

### 5.2 快照命名建议
建议文件名包含日期与范围，例如：
- tenant-wheel_v1_2026-05-09.zip

### 5.3 复用到新业务项目的方式
- 直接复制这三个目录到新项目
- 先把 docs/ 中的系统地图更新为新业务名
- 在 backend 增加新业务表时，每次只新增迁移文件（migrations/xxx.sql），不要改旧迁移
