# 租户平台 MVP：系统地图（给产品/小白）

## 1. 这阶段做什么、不做什么

### 做（MVP）

- 平台超级管理员登录（全局视角）
- 创建/启用/停用租户（企业客户）
- 创建租户管理员账号（每租户 1 个，用于该租户登录与使用系统）
- 租户管理员登录（租户视角）
- 多租户基础框架：租户内数据统一用 tenant\_id 隔离（为后续业务接入打地基）

### 不做（本阶段明确不实现）

- 售货机业务功能（设备/商品/库存/订单等）
- API 配置（按租户级配置，后续再做）
- 租户侧员工子用户、角色、页面权限（每租户只有 1 个用户在使用系统）
- 计费、审计日志、复杂组织架构、多因子登录等

## 2. 角色与权限边界（非常重要）

### 平台超级管理员（Platform Admin）

- 用途：管理整个系统与所有租户(单独的管理员页面)
- 能做：创建/停用/启用租户；重置租户管理员密码（建议有）
- 不能做：不参与任何租户业务数据操作（业务接入后也不应越权）

### 租户管理员（Tenant Admin）

- 来源：平台创建租户时绑定（每租户 1 个）
- 权限范围：仅限自己的租户
- 默认权限：租户内“全权限”（因为没有子用户/角色体系）
- 能做：登录并使用该租户的系统功能（后续业务接入后使用）

## 3. 页面清单（MVP）

### 平台管理端（平台超级管理员）

- 登录页
- 租户列表
- 创建租户（含：租户名称 + 租户管理员账号/密码/显示名）
- 启用/停用租户
- 重置租户管理员密码（可选但强烈建议）

### 租户端（租户管理员）

- 登录页
- 首页/概览（可为空壳，用于验证“能登录且能拿到 tenant\_id”）
- 我的账号（显示名、修改密码可选）

## 4. 多租户隔离规则（必须“强约束”）

### 数据分类

- 全局数据（不属于任何租户）：租户列表、平台管理员账号
- 租户数据（必须带 tenant\_id）：租户管理员账号（或其租户归属）、后续所有业务数据、以及未来的租户内子用户/权限数据

### 隔离底线（必须满足）

- 任何“租户数据”的新增/查询/修改/删除都必须绑定 tenant\_id
- tenant\_id 不能由前端随便传来就信任，必须来自“后端确定的租户上下文”
- 平台端的接口默认不使用租户上下文（平台端是全局视角）

## 5. 最小数据对象清单（数据库概念层）

> 名称可调整，但建议保持这个结构，便于后续扩展。

### Tenant（租户）

- tenant\_id
- name
- status（启用/停用）
- created\_at

### PlatformAdmin（平台管理员）

- admin\_id
- account
- password\_hash
- status

### TenantAdmin（租户管理员，每租户 1 个）

- tenant\_admin\_id
- tenant\_id
- account
- password\_hash
- display\_name
- status（启用/禁用）

## 6. 关键流程（用例级，方便对齐研发）

### 6.1 平台管理员登录

- 输入：账号 + 密码
- 输出：平台管理员登录态（用于调用平台管理端接口）

### 6.2 创建租户（平台端）

- 输入：租户名称、租户管理员 account/password/display\_name
- 系统动作：
  - 创建 Tenant
  - 创建 TenantAdmin（绑定 tenant\_id）
- 输出：租户创建成功

### 6.3 租户管理员登录（租户端）

- 输入：账号 + 密码
- 输出：租户登录态（必须包含 tenant\_id）
- 备注：后端每次请求都能拿到“当前 tenant\_id”

## 7. 未来扩展点（只预留，不实现）

### 7.1 租户侧账号与页面权限

- 未来当“一个租户多人使用”时，会新增：员工用户、角色、页面权限
- 建议做法：租户管理员默认全权限；员工通过角色控制页面访问

### 7.2 数据权限（资源范围）

- 本阶段只有“租户管理员全权限”，不实现页面权限体系
- 未来接业务后，会新增“能看到哪些设备/点位/线路”的数据范围控制
- 规则：先判页面权限（功能），再判数据范围（资源）

## 8. 低用量协作方式（减少 token 的约定）

### 问题反馈模板（你以后提 bug 用这个就够）

- 发生位置：哪个页面/接口（名称）
- 期望结果：你希望发生什么
- 实际结果：现在发生了什么（含报错截图/文字）
- 相关线索：涉及哪些文件路径/模块名（如果有）

### 定位优先级（你可以直接分类）

- 登录鉴权问题（登录不上/会话失效）
- 租户隔离问题（A 租户看到 B 租户数据，最高优先级）
- 页面权限问题（该看到/不该看到的页面）
- 业务问题（后续才会出现）
